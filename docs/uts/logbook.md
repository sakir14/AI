- Foto kegiatan asli di laboratorium dan/atau dokumentasi pengerjaan mandiri.

- Tautan repository bersama beserta source code dan petunjuk menjalankan.
- Screenshot hasil uji yang cocok dengan catatan kasus uji di laporan.
- Salinan presentasi akhir dan laporan PDF yang diserahkan.
